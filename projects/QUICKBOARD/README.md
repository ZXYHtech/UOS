# QuickBoard

QuickBoard 是一个零依赖、离线可用的个人 Kanban 任务看板，也是 UOS 单仓调度阶段的第一个普通业务试验项目。

它只使用浏览器原生的 HTML、CSS 和 JavaScript，不需要安装依赖、不需要构建、不需要后端服务，也不会访问 AI_book 或其他仓库。

## 如何运行

最简单的方式：

1. 打开 `projects/QUICKBOARD/` 目录；
2. 用现代浏览器直接打开 `index.html`；
3. 点击“新建任务”开始使用。

也可以用任意本地静态文件服务器打开这个目录，但这不是必需条件。

## 功能

- 新建任务；
- 编辑标题、描述和状态；
- 删除任务，并在删除前确认；
- 在“待办 / 进行中 / 已完成”之间移动任务；
- 三列任务数量实时更新；
- 空列显示清晰的空状态；
- 状态操作可以通过键盘完成，不依赖拖拽；
- 数据自动保存在浏览器 `localStorage`；
- 页面刷新或重新打开后恢复任务；
- 窄屏自动切换为纵向布局；
- 无外部字体、图片、框架、CDN 或包管理器依赖。

## 数据保存

QuickBoard 使用以下 localStorage 键：

```text
quickboard.cards.v1
```

每次成功创建、编辑、移动或删除任务后都会立即尝试保存。

需要注意：

- 数据只属于当前浏览器、当前用户配置和当前页面来源；
- QuickBoard 不提供账号、云同步或跨设备同步；
- 清除浏览器网站数据可能删除任务；
- 浏览器拒绝 localStorage 写入时，当前页面仍可继续操作，但相关更改可能无法在刷新后保留；
- 读取到损坏或不合法的存储数据时，应用会安全回退为空看板，而不是让页面崩溃。

## 使用说明

### 新建任务

点击页面顶部的“新建任务”，填写标题。描述可选，状态默认是“待办”。保存后卡片立即出现在对应列中。

### 编辑任务

点击卡片上的“编辑”，修改标题、描述或状态并保存。任务 ID 和创建时间保持不变。

### 移动任务

每张卡片都提供带标签的状态下拉框。直接选择“待办”“进行中”或“已完成”即可移动任务。这个方式同时支持鼠标、触控和键盘，不要求拖拽。

### 删除任务

点击“删除”后浏览器会要求确认。确认后任务会从本地存储和看板中删除。

## 可访问性与安全边界

V1 重点保证：

- 使用原生标题、按钮、表单标签和选择控件；
- 所有核心操作可以通过键盘完成；
- 提供可见的键盘焦点；
- 状态同时以文字表达，不只依赖颜色；
- 重要操作通过 live region 向辅助技术播报；
- 用户输入通过 DOM `textContent` 渲染，不把标题或描述作为 HTML 注入页面；
- 不执行任何网络请求，也不加载第三方代码。

## 项目边界

这是 `ZXYHtech/UOS` 仓库内部的 `SAME_REPOSITORY` 项目。

它的目的之一是验证 UOS 是否可以完成：

```text
项目定义
→ 任务发布
→ Claim
→ 工作
→ Done
→ 依赖解锁
→ Review
```

QuickBoard **不依赖 AI_book，不向 AI_book 写入内容，也不承担跨仓调度测试**。多仓调度属于 UOS 后续阶段，只有在 operator 明确开启后才会进行。
