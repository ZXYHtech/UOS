Generate one independent phone-vertical schematic travel route base image for a one-day Dujiangyan itinerary. This is an operational travel-map illustration, not a fantasy map and not a literal GIS screenshot.

Composition: portrait 9:16, clean light background, top-to-bottom trip flow. Show a compact rail segment from Xipu into central Dujiangyan, then a clearly separate scenic-area cluster built around the Min River hydraulic system, then an old-city/evening cluster, then the rail return. Use simple station, gate, river, bridge, heritage-site, meal/rest and rail icons connected by arrows. Keep generous whitespace for later vector labels.

Authoritative stop order:
Xipu rail -> Lidui Park station -> Dujiangyan Scenic Area Gate 1 / Lidui-side entry -> Baopingkou -> Feishayan -> Yuzui -> optional Anlan Bridge branch -> return/continue toward scenic-area south/old-city side -> Guanxian Ancient City -> formal-meal area placeholder -> Nanqiao riverfront -> Lidui Park station -> Xipu rail return.

Geographic logic that must be visually respected:
- Lidui Park station and Dujiangyan station are different; do NOT draw Dujiangyan station in this route.
- Baopingkou, Feishayan and Yuzui are one connected hydraulic-system visit, not three distant city attractions.
- Nanqiao and Guanxian Ancient City form a central urban/evening cluster near the scenic-area edge.
- Anlan Bridge is optional and must look like a branch/conditional extension rather than a mandatory remote detour.

Rendering constraints:
- base render only, no readable Chinese/English text, no logos, no brands, no fake street names, no invented gate numbers, no decorative fake bridges/roads.
- no exact home-origin point.
- do not show a subway into the scenic area.
- do not invent restaurant names.
- use schematic relative placement, not precise scale.
- leave clean callout spaces so a later vector layer can add verified Chinese labels and durations.

Visual tone: professional travel-planning infographic, calm, modern, practical, easy to read on a phone, culturally respectful, with subtle Sichuan river/heritage visual cues rather than tourist-poster decoration.
