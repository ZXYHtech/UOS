## 0. V6 是什么

V6 把项目此前的公共研究与 23 份 depth dossier 整合成一套可执行、可搜索、可做手机端展示的都江堰一日游知识底座。它不追求“景点越多越好”，而追求四件事：

1. 第一次到都江堰时真正看懂鱼嘴、飞沙堰、宝瓶口的系统关系；
2. 在步行、爬升、排队、天气、用餐与返程之间留出真实缓冲；
3. 把灌县古城、南桥与本地饮食作为水利文化之后的城市生活补充，而不是另一个打卡清单；
4. 所有会变化的事实——入口、内部流线、商户营业、铁路班次、实时 ETA、天气和客流——都明确标成“执行前刷新”，不伪装成永久事实。

【核心结论】

- 首次游览的最高价值核心仍是 **鱼嘴 + 飞沙堰 + 宝瓶口**，并且要有短而清楚的工程解释。
- **离堆公园站**通常是景区/古城中央片区最省接驳的铁路到发点；**都江堰站**是独立车站，在晚间可作为返程韧性备选，二者不得混淆。
- **都江堰景区 1 号门**目前是证据较强的城市侧入口；**秦堰楼 6 号门**不能写成每天保证可进，任何高进低出方案都要临行复核。
- 南桥夜间值得作为可选收尾，但不能承诺固定“蓝眼泪”颜色、固定亮灯效果或现场一定与网图相同。
- 公开资料没有可复核的 2026 都江堰景区年龄/出游目的百分比，也没有普通 9 月周六相对工作日的客流倍率；本书不制造这些数字。
- 法定节假日存在真实的售罄/高客流风险；普通非节假日必须靠临行前预约、客流预警和实时交通刷新，而不是套用节假日极值。

# 第一章｜先理解空间：四个区域，不要把所有点混在一起

## 1. 中央铁路到发层

### 离堆公园站

- 角色：景区、南桥、灌县古城中央片区的优先铁路到发节点。
- 与 1 号门/南桥：按当前高德快照，步行规划约 12–18 分钟。
- 风险：高德同时存在“离堆公园(公交站)”和“离堆公园快铁站(公交站)”等公交 POI，不能冒充铁路站。
- 执行规则：铁路时刻与余票必须用目标日期官方渠道刷新。

证据：`spots/LIDUI_PARK_STATION.md`、`field/AMAP_TIME_MATRIX.md`、`evidence/POI_SOURCE_AUDIT.md`。

### 都江堰站

- 角色：独立铁路站，距中央景区/古城步行集群更远。
- 优势：晚间某些时段候选班次比离堆公园站更密，可作为返程韧性备选。
- 代价：需要道路接驳，必须比较“到站 ETA + 站内缓冲 + 等车时间”，不能只看列车发车时刻。

证据：`spots/DUJIANGYAN_STATION.md`、`field/RETURN_RAIL_MATRIX.md`。

## 2. 景区城市侧入口层

### 都江堰景区 1 号门

2026 年运营材料与当前高德 POI 都支持 1 号门作为真实门点。它可作为五套基础方案的默认城市侧入口锚点，但具体日期的“可进/只出/临时管控”仍以当天景区规则为准。

证据：`spots/GATE1.md`、`evidence/POI_SOURCE_AUDIT.md`。

### 秦堰楼 / 高位入口

秦堰楼本体是稳定景点，但“秦堰楼 6 号门每天可入园”没有足够的 2026 当前证据。历史官方流线证明 6 号门这个门号真实存在，却不能把历史管理规则永久化。

**规则：**任何“高进低出”路线都只能写成条件路线：`高位入口在 T-1/当天确认可进入 → 执行；否则自动改回 1 号门城市侧路线。`

证据：`spots/QINYAN.md`、`evidence/POI_SOURCE_AUDIT.md`。

## 3. 水利核心层

鱼嘴、飞沙堰、宝瓶口不是三个彼此独立的“景点”，而是一套协同水利系统。

### 鱼嘴分水堤

理解重点：分流岷江，让内外江承担不同的供水、灌溉与泄洪角色。它最适合讲“因势利导”——不是用一座大坝硬挡水，而是借地形、水势和河道关系让系统工作。

证据：`spots/YUZUI.md`、`research/HISTORY_CULTURE.md`。

### 飞沙堰

理解重点：溢洪、排沙和调节。游客若只看景观很容易低估它；把它放在鱼嘴与宝瓶口之间解释，才能理解古代工程为什么具有自调节特征。

证据：`spots/FEISHAYAN.md`、`research/HISTORY_CULTURE.md`。

### 宝瓶口

理解重点：人工凿开的狭窄进水口形成天然流量控制瓶颈，是水进入成都平原灌区的重要控制点。伏龙观/离堆一侧适合作为历史背景与宝瓶口观察的组合节点。

证据：`spots/BAOPINGKOU.md`、`spots/FULONG.md`。

## 4. 山侧文化层

### 安澜索桥

价值：帮助理解两岸空间关系，也有独立桥梁历史与景观价值。风险：桥面是窄节点，高客流时容易形成持续人流和拍照瓶颈。

**规则：**排队明显、天气差或体力下降时可跳过，不让一座桥绑架全日节奏。

证据：`spots/ANLAN.md`、`evidence/REVIEWS_2026.md`。

### 二王庙

价值：把李冰父子与长期治水维护传统从“工程故事”转为“人的故事”。代价：山侧路线意味着更多爬升、台阶和时间。

证据：`spots/ERWANG.md`。

### 秦堰楼

价值：高位观察与山侧文化路线。它适合历史深度方案，但不应因为“看起来顺路”就强制加入每个首次路线。

证据：`spots/QINYAN.md`。

## 5. 城市生活层

### 灌县古城

作用：把白天的水利遗产转入真实城市生活、步行、餐饮与休息。商业化和便利性同时存在，因此“店铺多”不能自动等于“本地文化浓”。

证据：`spots/GUANXIAN_OLD_CITY.md`、`evidence/REVIEWS_2026.md`。

### 南桥

作用：免费的城市河岸/廊桥收尾节点。桥、水流和夜间氛围是相对稳定的价值；网络上非常强烈的蓝色水面效果则受灯光、水色、天气、手机成像和后期影响。

**规则：**南桥是可选高潮，不是全日唯一高潮；如果返程、天气或体力变紧，白天/傍晚经过也有独立价值。

证据：`spots/NANQIAO.md`、`evidence/REVIEWS_2026.md`。

# 第二章｜五套真正不同的一日方案

所有方案都使用“相对时段 + 时长 + 切换条件”，不在公共版本写入任何私人精确出发时间。

## 方案 A｜平衡经典：第一次来最稳

**适合：**第一次到都江堰，希望水利核心、古城、正餐和南桥都有，但不把一天塞满。

**基础顺序：**

离堆公园站 → 1 号门 → 伏龙观/宝瓶口 → 飞沙堰 → 鱼嘴 → 安澜索桥（条件允许） → 城市侧退出 → 灌县古城 → 正式坐餐 → 南桥 → 离堆公园站 / 都江堰站返程。

**体力：**中等。安澜索桥是第一可删项；不默认加入二王庙和秦堰楼。

**为什么这样排：**把最重要的水利理解放在体力最好、时间最可控的前半段；古城与南桥放后半段，天然可以吸收景区排队、用餐和返程时刻变化。

**切点：**
- 安澜索桥排队长 → 直接删；
- 景区超时 → 缩短古城闲逛，不删铁路缓冲；
- 南桥夜景等待会逼近返程保护窗 → 不等完全入夜。

来源：`research/ROUTE_PATTERNS.md`、`field/RAIN_CROWD_DECISION_TREE.md`。

## 方案 B｜历史文化深度：把都江堰真正看懂

**适合：**对李冰、治水思想、古代工程和文化节点兴趣明显高于逛街/小吃。

**优先路线（条件版）：**

离堆公园站 → 经实时确认的高位入口 → 秦堰楼/二王庙 → 安澜索桥 → 鱼嘴 → 飞沙堰 → 宝瓶口/伏龙观 → 古城边缘短休 → 简洁正餐 → 南桥 → 返程。

**入口不满足时自动降级：**

离堆公园站 → 1 号门 → 宝瓶口/伏龙观 → 飞沙堰 → 鱼嘴 → 安澜索桥 → 二王庙（体力允许） → 城市侧退出。

**体力：**中高，必须把爬升单独写出来，不能藏在“总步数”里。

**解释顺序：**
1. 鱼嘴：如何分水；
2. 飞沙堰：如何溢洪排沙；
3. 宝瓶口：如何控制进入平原的水；
4. 二王庙：为什么一个工程要靠两千多年持续维护才能成为“活遗产”。

**切点：**高位入口未验证、雨后山侧湿滑、体力明显下降 → 放弃高位路线，回到 1 号门核心方案。

来源：`research/HISTORY_CULTURE.md`、`spots/ERWANG.md`、`spots/QINYAN.md`、`evidence/POI_SOURCE_AUDIT.md`。

## 方案 C｜美食 + 灌县古城：水利核心之后看“活的城市”

**适合：**希望都江堰不只有景区，还要有本地小吃、古城慢走和一顿舒服正餐。

**基础顺序：**

离堆公园站 → 1 号门 → 宝瓶口 → 飞沙堰 → 鱼嘴 → 安澜索桥（仅低排队时） → 城市侧退出 → 代表小吃 → 古城慢走 → 饮品/休息 → 正式川菜 → 南桥 → 返程。

### 代表小吃：赵卖面

2026-09-03 当前页面支持“赵卖面”仍在杨柳河街/古城小吃带，当前营业快照为白天时段、人均较低。代表性品类以甜水面、红油水饺为主。

**规则：**只在路线本来经过古城/杨柳河街时顺路吃；长队或售罄就跳过，不为了名气跨区绕行。

来源：`food/REPRESENTATIVE_SNACK.md`。

### 正餐候选 1：庭院小酌（瑞莲街店）

当前跨平台地址一致性较高，适合景区/古城段前后的川菜坐席餐。当前价格和营业时段属于 2026-09-03 商户快照，执行日必须再次确认。

来源：`food/COURTYARD_MEAL.md`。

### 正餐候选 2：西街往事私房菜

适合古城慢逛中的安静院落正餐；当前平台对巷口定位大体一致，但门牌表达存在差异，因此必须以当日地图落点和商户信息二次确认。

来源：`food/QUIET_OLD_CITY_MEAL.md`。

**切点：**正餐排队过长 → 换同片区当前正常营业的坐席餐，不让一家店成为路线单点故障。

## 方案 D｜舒适低赶路：把“少一点”当成设计目标

**适合：**更看重体力、休息和从容感，而不是完成最多节点。

**基础顺序：**

离堆公园站 → 1 号门 → 宝瓶口/伏龙观 → 飞沙堰 → 鱼嘴 → 安澜索桥（双方都想走且不排长队才去） → 城市侧退出 → 长一点的正式坐餐 → 短古城步行 → 安静饮品/休息 → 南桥 → 返程。

**明确不默认加入：**二王庙、秦堰楼、高位入口、多个重复拍照点、付费夜游产品。

**体力规则：**公共研究里的约 15k 步只能作为规划参考上限，不是必须完成的指标。出现中度疲劳时先坐下 10–20 分钟，再删桥、爬升、重复拍照，而不是继续“凑步数”。

来源：`field/RAIN_CROWD_DECISION_TREE.md`、`evidence/REVIEWS_2026.md`。

## 方案 E｜天气 / 拥堵韧性：现场能改才是真的计划

**适合：**天气不稳定、周末客流不确定，或希望一路根据现场情况调整。

**基础核心：**

离堆公园站 → 1 号门 → 宝瓶口 → 飞沙堰 → 鱼嘴。

**可选分支：**
- 安澜索桥 / 山侧：只有天气、地面、队列和体力都舒服时才加；
- 古城坐餐：雨势增加或疲劳出现时可提前；
- 南桥：条件舒服才继续，否则直接返程；
- 返程：离堆公园站与都江堰站同时保留到最终票务/道路判断。

**最高优先级：**官方闭园、危险区域暂停、雷暴/强降雨、山洪或地灾提示 > 任何行程完整度。

来源：`field/RAIN_CROWD_DECISION_TREE.md`、`field/RETURN_RAIL_MATRIX.md`。

# 第三章｜工程理解：三分钟把都江堰看懂

## 1. 它不是“一座古代大坝”

都江堰的核心思想不是把岷江堵住，而是利用地形、河道曲率、流速和高差，让分流、泄洪、排沙和进水平衡协同工作。系统在历史中持续维护、修复和调整，因此不能说所有构造两千多年“原样不变”。

## 2. 三个节点是一套因果链

```text
岷江来水
  ↓
鱼嘴：先分流
  ↓
飞沙堰：再溢洪 / 排沙 / 调节
  ↓
宝瓶口：控制进入成都平原灌区的水量
```

游客评论审计显示，“是否理解这套工程”会明显影响体验。V6 因此把工程解释前置，而不是把讲解藏在行程末尾。

来源：`research/HISTORY_CULTURE.md`、`evidence/REVIEWS_2026.md`。

# 第四章｜交通与返程：不要让最后一小时毁掉整天

## 1. 中央交通原则

- 默认优先研究离堆公园站，因为它与 1 号门、南桥、古城属于中央短距离关系；
- 都江堰站保留为独立备选；
- 公交站 POI 不承担铁路站身份；
- “看起来地图上很近”不等于存在可走入口或车辆通道。

来源：`field/AMAP_TIME_MATRIX.md`、`evidence/POI_SOURCE_AUDIT.md`。

## 2. 离堆公园站的返程保护窗

南桥/1 号门到离堆公园站当前静态步行约 12–18 分钟；铁路还要加进站、安检、找检票口的 20–30 分钟。正常规划应在目标车发车前约 **35–50 分钟**从南桥/1 号门区域开始向站移动，雨天、节假日、第一次使用时取上限。

## 3. 都江堰站的切换算法

若离堆公园站晚间出现班次空档、无合适票或时间错位：

1. 先确认都江堰站候选车票；
2. 再读取高德“当前位置 → 都江堰站”实时道路 ETA；
3. 实时 ETA 上再加 20–30 分钟站内缓冲；
4. 若总裕度偏紧，选下一班而不是赌道路和安检都无延误。

## 4. 时刻表边界

`RETURN_RAIL_MATRIX.md` 保存的是 2026-09-03/04 公共查询快照，用于识别班次密度与切站逻辑，**不是未来日期的票务保证**。最终执行必须重新查 12306/铁路官方目标日期信息。

# 第五章｜吃什么：一顿正餐 + 一两个代表口味就够

## 1. 正餐原则

优先级：正常营业 → 路线顺 → 有座位可恢复体力 → 价格合适 → 口碑/名气。

不建议为了某一家店跨城区往返，也不建议在已经疲劳时继续“集邮式”吃多家。

## 2. 当前三张食物卡

### 庭院小酌（瑞莲街店）

- 类型：川菜正餐；
- 当前角色：景区/古城后的正式坐席餐；
- 当前证据：跨平台位置一致性较高；
- 动态项：营业时间、菜价、排队、是否可留座。

### 西街往事私房菜

- 类型：古城院落私房菜；
- 当前角色：希望环境更安静时的古城正餐；
- 动态项：门牌表达、营业、菜单、座位。

### 赵卖面

- 类型：代表性小吃；
- 当前角色：古城/杨柳河街顺路小份试吃；
- 动态项：营业、热门品类售罄和排队。

来源：`food/` 三份 depth dossier。

# 第六章｜预算：500 元两人公共规划框架

旧公共预算模型显示，两人约 500 元的一日基础目标具有可行性，前提是：

- 核心水利景区门票和铁路返程优先；
- 保留一顿正常坐席正餐；
- 小吃只选代表性品类；
- 付费夜游、重复交通、重复小吃等作为可删项；
- 价格均属于规划快照，实际门票、车票和商户价格必须刷新。

公共预算优先级：

**景区核心 > 可靠返程 > 正式坐餐 > 水/休息/天气弹性 > 代表小吃 > 可选付费项目。**

付费夜游不作为五套基础方案默认项目；免费南桥/古城河岸更适合控制预算和保持返程弹性。

来源：`research/BUDGET_MODEL.md`。

# 第七章｜游客与季节：只说有证据的，不制造人群百分比

## 1. 游客画像

截至 2026-09-03，没有找到可公开复核的都江堰景区 2026 年年龄百分比或出游目的百分比表。

可以安全使用的定性客群包括：

- 文化遗产 / 水利工程型；
- 亲子 / 学生 / 研学型；
- 成都周边短途休闲型；
- 年轻体验 / 徒步 / 社交场景型；
- 入境游客型；
- 综合目的型。

这些类别相互重叠，不能相加到 100%。

来源：`evidence/VISITOR_PROFILE_AUDIT.md`。

## 2. 季节与客流

可以确认：春节、五一、国庆等重大假日存在真实高客流、售罄或预警；2026 暑运铁路数据也支持夏季交通需求强。

不能确认：

- 1–12 月各月游客占比；
- 普通 9 月周六比工作日多多少百分比；
- 某个普通周末一定拥挤或一定清闲。

因此五套方案都采用“弹性缓冲 + 临行前刷新”，而不是给普通周末贴一个伪精确客流等级。

来源：`evidence/SEASONALITY_AUDIT.md`。

# 第八章｜现场设施与恢复

## 1. 厕所

景区主游线存在多处卫生间，但没有足够可靠的 2026-09-03 官方逐点开放清单。入园后在游客中心/入口服务区先解决一次；看到明确厕所指示且已有需求时就用，不假设山坡、寺庙或桥梁节点一定有开放厕所。

## 2. 游客中心 / 服务

游客中心、综合服务窗口和官方服务电话可承担票务、现场规则与设施咨询。地图显示有设施，不等于当天必开放。

## 3. 观光车

把观光车当作体力保护工具，不当作时间保证。如果观光车排队本身变成时间黑洞，应根据体力与路线选择继续步行或删节点。

来源：`field/FACILITIES.md`。

# 第九章｜异常情况：一条优先级管到底

```text
人身安全
  > 返程可控
  > 鱼嘴 / 飞沙堰 / 宝瓶口
  > 正式坐餐与恢复
  > 安澜索桥 / 二王庙 / 秦堰楼 / 单一拍照点 / 夜景
```

## 小雨

核心先走；坡、桥、拍照节点后置；湿滑处降速；利用游客服务区、厕所和坐席恢复。

## 强降雨 / 雷暴 / 山洪 / 地灾提示

不进入危险区域、不绕过官方管控、不在河边/桥梁附近等待；转安全室内、古城坐餐或提前返程。

## 拥堵

- 桥和单一摄影平台排队长 → 跳过；
- 官方暂停进入 → 不等待“赌一会儿会开放”；
- 观光车排队长 → 视体力决定步行或删点。

## 疲劳

- 轻度：补水、短休；
- 中度：坐 10–20 分钟，删桥、爬升和重复拍照；
- 明显不适：停止游览并寻求现场工作人员/医疗支持。

## 晚到 / 用餐拖延

先保护水利核心和返程，后删山侧、拍照、夜景；不以“已经排了这么久”为理由继续沉没成本。

来源：`field/RAIN_CROWD_DECISION_TREE.md`。

# 第十一章｜证据边界与写作禁区

## 可以直接写

- 三大水利核心的历史与工程逻辑；
- 离堆公园站和都江堰站是不同铁路站；
- 重大法定节假日存在高客流风险；
- 南桥/古城与景区城市侧属于中央收尾集群；
- 山侧节点增加体力和爬升成本；
- 当前商户/铁路/地图快照，但必须带日期与动态 caveat。

## 必须降级成“规划假设”

- 普通周末具体拥挤等级；
- 某时段比另一时段少多少人；
- 高位入口在未来某天一定开放；
- 某家店未来某天一定营业/免排队；
- 某班列车未来某日一定有票。

## 禁止写

- 无来源的游客年龄、目的、抱怨或月度客流百分比；
- 把青城山—都江堰组合景区数字写成都江堰水利景区单体；
- 把公交站当铁路站或景区门；
- 把旧博客/旧截图的入口状态永久化；
- 把“都江堰水利工程景区”等近重复地图名称画成第二个独立景点；
- 任何私人出发点、私人时间、关系、礼物或私人聊天内容。

# V6 最终编辑原则

**少承诺、强证据、留弹性。**

一份可靠的一日游指南，不应该告诉读者“每分钟一定发生什么”，而应该明确：什么是稳定事实、什么是当前快照、什么需要临行确认，以及一旦天气、拥堵、疲劳或车次变化时，应该删什么、保什么、怎么切换。
