## 1. 核心结论

对于以都江堰景区、南桥、灌县古城为主的一日游，返程铁路应采用“两站并行、临场切换”的策略：

1. **离堆公园站是中央城区最省转移成本的优先返程站。** 从南桥/1号门一带步行到离堆公园站约按 12–18 分钟规划，再叠加 20–30 分钟进站/安检/找检票口缓冲，正常情况下应在列车发车前约 **35–50 分钟**开始离开南桥/1号门区域。
2. **都江堰站是更强的晚间韧性备选。** 2026-09-03/04 的公开时刻快照显示，都江堰站在 19:54–22:30 区间有多班前往犀浦的候选，而离堆公园站在 19:34 以后到 21:22 之间存在明显班次空档。
3. **不能只看“下一班车几点开”，必须同时计算“当前位置→车站”的接驳时间。** 都江堰站距中央景区/南桥片区更远，需实时读取高德道路 ETA，再额外叠加 20–30 分钟站内缓冲。
4. **公开时刻表不等于余票。** 携程等页面可作为车次/时间候选快照，但最终是否能买到票、车次是否临时调整，只能在 12306/铁路官方渠道或同等实时票务渠道确认。

### 4.1 为什么都江堰站不能机械替代离堆站

都江堰站的车次更密，并不等于从南桥出发总耗时更短：

- 南桥/1号门 → 离堆公园站属于中央城区短步行，静态规划约 12–18 分钟；
- 南桥/1号门 → 都江堰站需要道路接驳，低至中等交通压力下可按约 15–25 分钟规划，但必须用当天高德实时 ETA 覆盖；
- 到都江堰站后仍需至少预留 20–30 分钟站内缓冲。

因此，真正比较的是：

`当前位置到车站时间 + 站内缓冲 + 等车时间 + 列车运行时间`

而不是只比较列车发车时刻。

## 5. 两站缓冲规则

### 5.1 离堆公园站

从南桥/都江堰景区 1号门区域返程：

- 站外步行：约 **12–18 min**；
- 进站、安检、确认检票口：建议 **20–30 min**；
- 正常总保护窗：**35–50 min**。

因此，如果目标车次 21:22 发车，不应 21:00 才从南桥开始走。对第一次使用该站、下雨、节假日或人流大时，取缓冲上限。

### 5.2 都江堰站

从南桥/古城中央区域返程：

1. 打开高德读取“当前位置 → 都江堰站”实时驾车 ETA；
2. 对道路 ETA 额外加 **20–30 min** 站内缓冲；
3. 若高德实时 ETA 已高于静态 15–25 min 上限，以实时值为准；
4. 赶铁路时不建议把普通公交作为最后一刻的唯一保障。

示例：若某都江堰站车次 20:52 发车，而 20:05 时高德显示到站需要 25 min，则理论到站约 20:30，只剩 22 min 站内时间，已进入偏紧区；应优先选择下一班而不是赌道路和安检都无延误。

## 6. 现场切换决策树

### 情景 A：准备在 18:00–19:00 离开

- 先查离堆公园站 18:24 / 18:54 / 19:15 / 19:34 一带是否有适合且可购票候选；
- 如果满足“发车时间 - 当前时间 ≥ 35–50 min”，优先步行离堆站；
- 若票务不合适，再查都江堰站，不需要为了“必须从离堆回”而等待很久。

### 情景 B：19:34 左右的离堆候选赶不上

- 不压缩安全缓冲；
- 立即比较：
  - 离堆公园站下一组约 21:22 / 21:56；
  - 都江堰站约 19:54、20:18、20:27、20:52、21:03、21:12 等候选；
- 用“实时去都江堰站 ETA + 20–30 min 站内缓冲”判断是否值得切站。

### 情景 C：想看南桥夜景后再回

- 不预先承诺固定灯光时刻或固定“蓝眼泪”效果；
- 先在当天确认两站晚班余票，再决定夜景停留上限；
- 至少保留一个**不依赖最后一班**的后备车次；
- 如果天气、拥堵或餐饮拖延使后备车次也开始变紧，立即结束夜间停留。

### 情景 D：离堆无票/车次空档，但都江堰有合适候选

- 先确认都江堰站车票；
- 再叫车/打车前往；
- 不应先坐车去都江堰站、到站后才第一次查票。

## 7. 与五套方案的使用关系

- **A 平衡经典**：优先离堆公园站，减少返程接驳变量；
- **B 历史文化深度**：若山侧/高处节点导致结束较晚，提前同时锁定两站候选；
- **C 美食+古城**：晚餐时间最容易侵蚀铁路缓冲，19:34 前后必须做一次强制时刻刷新；
- **D 舒适低赶路**：宁可早一班离堆返程，不以“玩到最后一班”为目标；
- **E 天气/拥堵韧性**：两站都查，哪个有更大“门到车”时间裕度就选哪个。
