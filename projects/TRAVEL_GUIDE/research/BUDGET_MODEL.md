# Dujiangyan Two-Person One-Day Budget Model — target <= CNY 500

## Core conclusion

The CNY 500 two-person target is feasible for the intended day **if the separate paid night-tour product is not added by default** and the formal meal is kept in a sensible two-person price band.

## Fixed / near-fixed baseline

- Dujiangyan Scenic Area adult admission: approximately CNY 80 x 2 = **CNY 160**.
- Xipu-area suburban rail: commonly approximately CNY 10 per person per direction = **about CNY 40 round trip for two**.

Baseline fixed spend: **about CNY 200**.

Remaining planning envelope: **about CNY 300**.

Train fare and admission must be refreshed before the final private itinerary; this is a planning snapshot, not a guaranteed sale price.

## Recommended base budget

| Category | Two-person target | Notes |
|---|---:|---|
| Scenic admission | 160 | core paid attraction |
| Rail round trip | 40 | current common fare snapshot |
| Local taxi/bus contingency | 40-60 | station/route flexibility, rain/fatigue |
| Formal seated meal | 110-140 | aim for 2-3 dishes/staple/drink without premium ordering |
| Local snacks | 30-50 | 1-2 representative tastes, shared where practical |
| Dessert/drinks/water | 20-35 | rest value is more important than tasting everything |
| Buffer | 15-40 | price variance / small unplanned need |

**Base total:** roughly CNY 415-485.

## Low-cost version

- fixed 200;
- local movement 20-30;
- formal meal 90-110;
- snacks/dessert/water 50-65;
- buffer 20-30.

**Expected total:** roughly CNY 380-435.

This version requires more walking/public transport and a simpler formal meal, but should still feel like a complete day rather than a cost-cutting exercise.

## Comfort version

- fixed 200;
- local movement 50-70;
- formal meal 130-160;
- snacks/dessert/water 60-80;
- buffer 20-30.

**Expected total:** roughly CNY 460-540.

Therefore the comfort version needs active control: if the formal meal is near CNY 160, keep local rides/snacks lower to stay under CNY 500.

## Spending priorities

Under the stated goal, prioritize in this order:

1. scenic-area admission;
2. reliable rail return;
3. one comfortable formal meal;
4. water/rest and weather/fatigue flexibility;
5. a few representative snacks;
6. optional paid extras.

Do **not** spend the remaining budget on every internal paid shuttle/photo/night product merely because it is available.

## Night-tour decision

The 2026 `都江·夜堰` paid night-tour product has been reported at about CNY 80/adult. Adding two night-tour tickets would add roughly **CNY 160**, pushing the day well above the CNY 500 target unless food/local transport were cut aggressively.

Default project rule: **use the free Nanqiao / old-city riverfront evening atmosphere instead of the paid night-tour product**. A night-tour variant can be described as an optional over-budget upgrade, not part of the five base schemes.

## Gifts

Gifts already owned before the trip are treated as sunk cost and are excluded from the day-trip CNY 500 cash-spending target. Any relationship-specific gift details stay in encrypted project artifacts.

## Budget checkpoints for final phone PDF

Each private scheme should show three running checkpoints:

- after arrival + admission;
- after formal meal;
- before evening return.

If actual spend is running high, the first cuts should be optional paid attractions / extra ride / duplicate snacks, not return-ticket buffer or water/rest needs.
