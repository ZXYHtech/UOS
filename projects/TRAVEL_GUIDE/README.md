# TRAVEL_GUIDE

Standalone UOS pilot project for building a practical travel guide from a guided operator intake.

## Current step

`TASK_TRAVEL_GUIDE_INTAKE_01` — capture requirements before planning the itinerary.

## Planned flow

1. Confirm travel requirements.
2. Split only the necessary downstream planning tasks.
3. Verify time-sensitive travel facts when relevant.
4. Produce operator-visible itinerary/budget/booking guidance artifacts.
5. Review the final guide before project completion.

All outputs stay inside `projects/TRAVEL_GUIDE/`. This project does not dispatch or write to AI_book.
